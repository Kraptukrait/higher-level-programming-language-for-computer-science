## 💌 Welcome!

Hi, so glad you're here!

This is my **learning repo for the course "Higher Programming Languages."** "Higher" doesn't mean the code lives on a mountain 🏔️, but that we give computers instructions in languages that humans can also understand. Mostly. When the compiler is in a good mood.

This is where my exercises, experiments, and maybe small triumphs land, **week by week**. And yes, the mistakes too, because without them this would be a very short repo. 😅

> 💡 **My motto:** Coding works better with a dash of humor and a lot of heart.

## Why Programming Is for Everyone

Programming isn't just for "nerds in a dark basement," nor for any one particular group. It's:

- 🧩 **Solving puzzles:** like an escape room, just with a keyboard
- 🎨 **Being creative:** you build something from nothing
- 💪 **Sticking with it:** every mistake makes you better
- 🤝 **Sticking together:** together you get further and get through exams

If you're just starting out: **you can do this.** Everyone started at "Hello World," even the ones who later act like it was always easy. 💜

## ❓ FAQ (Questions Nobody Asked)

**Does the code always run?**
It runs when the stars align and the compiler is in a good mood. 🌟

**Why do you have so many commits?**
Because "save once" is only for brave people. 💾

**May I learn from you or copy?**
Learning: *absolutely!* Copying: please don't, because your exam won't write itself. 😉 Look at *how* it works, then build it yourself.

**I found a bug. Now what?**
Congratulations, you're a bug detective! 🕵️ Open an issue, I'd love any hints.

**How do I actually find bugs?**
Read your code out loud, go through it step by step, and if all else fails, explain it to a houseplant. 🪴 Surprisingly effective.
